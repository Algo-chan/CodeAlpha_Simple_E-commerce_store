# Assets

```
images/   product photos, category banners, illustrations
icons/    SVG icons (inline or as files)
fonts/    reserved for the brand webfonts chosen in the design phase
```

Nothing is committed here yet — the brand identity and visual design system are
defined in a later phase. Images should be WebP/AVIF with explicit dimensions to
avoid layout shift, and icons should be SVGs so they inherit `currentColor`.
