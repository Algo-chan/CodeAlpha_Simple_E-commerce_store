# Demo photo credits

These are placeholder photographs for the demo catalogue. Every file is used
under a **CC0 1.0** or **Public Domain Mark (PDM)** dedication, so no
attribution is legally required - this table exists so a source can be traced
and the set can be audited or replaced wholesale.

Files live at `assets/images/products/<slug>/<angle>.webp`, with a
`<angle>-thumb.webp` rendition beside each. `mock/products.js` names the
angles per product; `mock/media.js` builds the URLs. When the real catalogue
imagery arrives, delete these folders and drop the `photos` lists.

Sources were found through [Openverse](https://openverse.org); each row links
to its Openverse record, which carries the author and the licence deed.
